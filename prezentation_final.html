Medical Image Diagnosis System

Using Deep Learning & Transfer Learning

Automated, Zero-Choice Triage

The Problem

Time-Consuming

Hospitals process thousands of images daily. Manual interpretation by scarce radiologists causes critical delays in rural regions.

Complex UX

Existing AI tools require users to manually select the imaging modality and disease, introducing barriers for non-expert users.

Error-Prone Routing

Feeding an X-Ray into a Brain Tumor model yields false results. Lack of automated triage leads to diagnostic errors.

Our Solution & Objectives

"Zero-Choice" UI

User only uploads an image. The system handles detection, routing, and inference automatically.

Dynamic Model Routing

7 specialized Deep Learning models (EfficientNet-B0 & ResNet50) coordinate based on auto-detected image modality.

Explainable AI (XAI)

Generates Grad-CAM heatmaps visually highlighting anatomical regions influencing the AI's prediction.

Automated Reports

Generates downloadable PDF diagnostic reports containing predictions, confidence scores, and heatmaps.
