## ✨ Features

- 🧠 **Zero-Choice User Experience:** Simply upload an image. The system handles modality detection, routing, and inference automatically.
- 🩺 **Multi-Modality Support:** Processes Chest X-rays, Brain MRIs, CT Scans, and Skin Lesion photographs.
- 🔬 **7 Specialized Deep Learning Models:** Powered by custom-trained `EfficientNet-B0` and `ResNet50` architectures.
- 👁️ **Explainable AI (XAI):** Generates Grad-CAM heatmaps to visually highlight anatomical regions influencing predictions.
- 📄 **Diagnostic PDF Reports:** Downloadable comprehensive reports containing predictions, confidence scores, and heatmaps.
- ⚡ **Production Ready:** Built with an asynchronous FastAPI backend and a responsive, animated React frontend.

## 🧠 Supported Models & Diseases

The system employs a multi-tier architecture. First, an **Image Type Classifier** detects the modality, then dynamic routing dispatches the image to the appropriate disease-specific model(s):

| Modality | Target Diseases | Model Architecture |
| :--- | :--- | :--- |
| **X-Ray** | Pneumonia, COVID-19, Cardiomegaly | EfficientNet-B0 |
| **Brain MRI** | Brain Tumor (Glioma, Meningioma, Pituitary) | ResNet50 |
| **CT Scan (Lung)** | Lung Cancer (Benign, Malignant) | ResNet50 |
| **Skin Photograph** | Skin Lesion (Melanoma, BCC, etc. - 7 classes) | EfficientNet-B0 |

---

## 🚀 How It Works

1. **Upload:** User uploads a medical image via drag-and-drop.
2. **Pre-processing:** The backend validates, resizes, center-crops, and normalizes the image.
3. **Modality Detection:** The image passes through the modality classifier to determine its type (e.g., X-ray vs MRI).
4. **Concurrent Inference:** The image is routed to the corresponding disease models in parallel.
5. **Grad-CAM:** A heatmap is generated for the highest-risk prediction to provide interpretability.
6. **Result:** The user is presented with a colour-coded probability dashboard, the interactive Grad-CAM viewer, and an option to export a PDF.

## 💻 Getting Started (Local Development)

## NOTE : These commands will perfectly work if you have python 3.9.x to 3.11.x and Node.js version less than 23 LTS.....
If you have python 3.12.x + and node.js 23+ then run the commands given in "CommandsToRun.md" file....

### Prerequisites
- Python 3.9+
- Node.js 18.x+
- Model weight files (`.pth`) placed in the correct backend directory.

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/medical-image-diagnosis.git
cd medical-image-diagnosis
```

### 2. Setup the Backend
```bash
cd main/backend
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 3. Setup the Frontend
```bash
cd main/frontend
npm install
npm run dev
```
The frontend will be available at `http://localhost:5173`.
